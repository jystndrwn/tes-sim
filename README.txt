===============================================================
       GAME LATIHAN SOAL UJIAN TEORI SIM C RESMI
===============================================================

Folder Game: D:\VIBE CODING\game tes sim

FILE DI DALAM FOLDER:
- index.html        (File utama untuk membuka dan memainkan game)
- style.css         (Desain tampilan modern, responsif, dan animasi equalizer)
- script.js         (Mesin logika kuis, 25 soal, timer 5 detik + jeda, kontrol audio)
- backsound.mp3     (File musik MP3 asli, instrumen fokus ujian yang tenang)
- README.txt        (Petunjuk penggunaan dan fitur lengkap)

CARA MEMBUKA & MEMAINKAN GAME:
1. Buka folder "D:\VIBE CODING\game tes sim" di File Explorer laptop/PC Anda.
2. Klik dua kali (double click) pada file:
   --> index.html
3. Game akan langsung terbuka di browser (Google Chrome, Edge, dll).
4. Tidak butuh koneksi internet (100% offline).

FITUR TERBARU (TIMER 5 DETIK & TOMBOL JEDA):
- ⏱️ HITUNG MUNDUR 5 DETIK + TOMBOL JEDA (PAUSE):
  * Begitu Anda memilih opsi jawaban, countdown 5 detik akan mulai berjalan otomatis.
  * Terdapat tombol [ ⏸️ Jeda Timer ]: Klik tombol ini kapan saja saat Anda ingin membaca penjelasan/alasan jawaban dengan tenang tanpa takut terburu-buru berpindah soal.
  * Saat dijeda, bar hitung mundur akan berhenti dan berubah menjadi mode baca (warna kuning hangat).
  * Anda bisa klik [ ▶️ Lanjutkan Timer ] untuk melanjutkan sisa detik, atau langsung klik tombol "Lanjut Sekarang ➔" jika sudah selesai membaca.

FITUR AUDIO & MUSIK:
- 🎵 File Asli "backsound.mp3" sudah tersedia dan siap diputar di dalam folder game.
- 🎛️ Audio Controller di Header:
  * Tombol Play/Pause (▶️ / ⏸️) untuk memutar musik sejak di halaman depan.
  * Animated Equalizer: Bar gelombang visual yang menari saat musik dimainkan.
  * Slider Volume: Sesuaikan volume musik (0% - 100%) dengan bebas.
  * Tombol Efek Suara (🔔 / 🔕): Mengatur suara efek jawaban benar/salah/detak.

FITUR EDUKASI:
- 25 Soal Resmi Ujian Teori SIM C lengkap dengan pembahasan UU Lalu Lintas.
- 2 Mode: Mode Latihan (pembahasan langsung) & Mode Ujian (timer 15 menit).
- Evaluasi kelulusan (standar 70%) & review 25 soal lengkap di akhir kuis.
